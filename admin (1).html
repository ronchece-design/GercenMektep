Панель управления

Здесь можно писать новости, открывать наборы и добавлять олимпиады. Войти может только владелец сайта: нужен ключ доступа.

Как получить ключ доступа
  1. Откройте github.com → ваша фотография → Settings.
  2. Слева внизу: Developer settings → Personal access tokens → Fine-grained tokens.
  3. Нажмите Generate new token и назовите его, например, «Сайт».
  4. В поле Repository access выберите Only select repositories и укажите GercenMektep.
  5. В Permissions → Repository permissions найдите Contents и выберите Read and write.
  6. Нажмите Generate token и скопируйте ключ. Он показывается один раз.

Никому не отправляйте ключ. Он сохраняется только в вашем браузере.
